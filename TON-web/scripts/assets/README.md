# Документация TON Pay - Типы и структура

Этот файл содержит описание всех типов документации, которые необходимо заполнить для проекта TON Pay, а также инструкции по заполнению файла `index.html`.

## 📝 Как заполнять index.html

### Структура навигации (Sidebar)

Навигация находится в блоке `<div class="idocs-navigation bg-light">` и имеет следующую структуру:

```html
<li class="nav-item"><a class="nav-link active" href="#idocs_start">Название раздела</a>
  <ul class="nav flex-column">
    <li class="nav-item"><a class="nav-link" href="#idocs_subsection">Подраздел</a></li>
  </ul>
</li>
```

**Важно:**
- `href` должен начинаться с `#` и соответствовать `id` секции
- `active` класс добавляется только к активному пункту верхнего уровня
- Вложенные пункты не имеют класса `active`

### Структура контента

Каждая секция документации должна быть обернута в:

```html
<section id="idocs_section_name">
  <h2>Заголовок секции</h2>
  <p>Описание...</p>
  
  <!-- Подсекция -->
  <section id="idocs_subsection">
    <h3>Заголовок подсекции</h3>
    <p>Содержимое...</p>
  </section>
  
  <hr class="divider">
</section>
```

**Важно:**
- `id` секции должен совпадать с `href` в навигации (без `#`)
- Используйте `<hr class="divider">` для разделения секций
- Заголовки: `<h1>` для главного, `<h2>` для разделов, `<h3>` для подразделов

### Форматирование кода

Для примеров кода используйте:

```html
<pre><code class="language-name">код здесь</code></pre>
```

**Поддерживаемые языки:**
- `python` - для Python кода
- `php` - для PHP кода
- `javascript` - для JavaScript кода
- `json` - для JSON
- `bash` - для команд терминала
- `html` - для HTML

**Пример:**
```html
<pre><code class="python">import requests

response = requests.post('https://pay.whaile.ru:3000/create_payment', json={
    'cashier_id': 1,
    'amount': 0.01,
    'wallet': 'UQ...'
})
</code></pre>
```

### Экранирование HTML в коде

При вставке HTML кода в `<pre><code>`, экранируйте специальные символы:
- `<` → `&lt;`
- `>` → `&gt;`
- `&` → `&amp;`

Или используйте класс `html` для автоматического экранирования через highlight.js.

### Порядок заполнения

1. **Обновить навигацию** - добавить пункты меню в sidebar
2. **Создать секции** - добавить `<section id="...">` с контентом
3. **Добавить примеры** - вставить примеры кода
4. **Проверить ссылки** - убедиться, что все `href` соответствуют `id`

## 📌 Заметки

- Все суммы должны быть с 2 знаками после точки
- Все валюты отображаются в верхнем регистре (TON, JETTON)
- Таймаут платежа: 20 минут
- Минимальная сумма платежа: 0.01
- Минимальная сумма вывода: 0.01
- Все ID в базе данных - целые числа (BIGINT AUTO_INCREMENT)
- Балансы хранятся только в таблице Cashiers, не в Users
